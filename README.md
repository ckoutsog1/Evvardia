# ΕυΒάρδια · Ερευνητικό πρωτότυπο καταγραφής συμβάντων

Τοπική έκδοση για συνθετικές δοκιμές, με Python 3.10+ και SQLite 3.38+. Εκτελείται στη διεύθυνση loopback του υπολογιστή. Χρησιμοποιείται αποκλειστικά με δοκιμαστικούς κωδικούς. Η διαδρομή υποστήριξης και οι μετρήσεις wearable παραμένουν προσομοιωμένες.

## Εκκίνηση

Αποσυμπιέστε το ZIP και ανοίξτε τερματικό στον φάκελο. Σε Windows μπορείτε να αντικαταστήσετε το `python` με `py`.

```text
python verify.py
python server.py add TEST-001
python server.py serve
```

Κρατήστε τον παραγόμενο δοκιμαστικό κωδικό και ανοίξτε http://127.0.0.1:8765 στον ίδιο υπολογιστή. Κάντε ένα check-in και υποβάλετε δεύτερη καταγραφή με την ίδια ημερομηνία. Μπορείτε επίσης να ανοίξετε την οθόνη υποστήριξης από το κουμπί στην κεφαλίδα. Η φωνητική λειτουργία χρειάζεται συμβατό browser και εγκατεστημένη τοπική αναγνώριση ελληνικών.

Από δεύτερο τερματικό στον ίδιο φάκελο, εξαγάγετε τα συμβάντα:

```text
python server.py export events.csv
```

Η εντολή δημιουργεί νέο CSV. Για νέα εξαγωγή δώστε νέο όνομα αρχείου. Το `study.sqlite3` περιέχει τις τοπικές εγγραφές της δοκιμής.

## Δεδομένα και ανάλυση

Το CSV περιέχει μοναδικό αναγνωριστικό συμβάντος, ψευδώνυμο συμμετέχοντα, τύπο συμβάντος, ώρα παραλαβής σε UTC, ημερομηνία check-in όπου εφαρμόζεται και προκαθορισμένο κωδικό τεχνικού σφάλματος. Μόνο το άνοιγμα της διαδρομής υποστήριξης καταγράφεται. Οι τιμές check-in εμφανίζονται κατά την τρέχουσα επίσκεψη της σελίδας. Η βάση συμβάντων δεν κρατά αυτές τις τιμές, ήχο, απομαγνητοφώνηση ή δεδομένα wearable. Αν η σύνδεση διακοπεί, οι εκκρεμείς αποστολές παραμένουν στη μνήμη της ανοικτής καρτέλας. Κλείσιμο ή ανανέωση της καρτέλας μπορεί να τις χάσει. Η επαναποστολή του ίδιου συμβάντος δεν δημιουργεί νέα εγγραφή.

Στο jamovi, εισαγάγετε το CSV και ορίστε participant_code και event_type ως ονομαστικές μεταβλητές. Για τον αριθμό ολοκληρωμένων check-ins ανά συμμετέχοντα, φιλτράρετε event_type == 'checkin_submitted' και υπολογίστε συχνότητες ανά participant_code. Το κύριο αποτέλεσμα της 8ης εβδομάδας καταγράφεται στο ξεχωριστό μητρώο της μελέτης για όλους τους εγγεγραμμένους.

## Επαλήθευση και χρήση με συμμετέχοντες

Το verify.py εκτελεί πραγματικά αιτήματα HTTP σε τοπική διεργασία με απομονωμένη συνθετική βάση. Ελέγχει έγκυρους και μη έγκυρους κωδικούς, απομόνωση συμμετεχόντων, ταυτόχρονη επαναποστολή, διόρθωση, αποσύνδεση και CSV. Οι έλεγχοι browser/μικροφώνου στη συγκεκριμένη έκδοση εκκρεμούν. Για συμμετέχοντες, απαιτείται μεταφορά σε εγκεκριμένη υποδομή του φορέα με HTTPS, διαχείριση ερευνητικής πρόσβασης και συμφωνημένη διαδικασία παραπομπής.

## Προαιρετικές κατευθύνσεις με LLM

Η ενότητα «Τι μπορώ να κάνω τώρα;» είναι απενεργοποιημένη από προεπιλογή. Όταν είναι απενεργοποιημένη, η σελίδα δεν περιλαμβάνει την ενότητα ή το JavaScript της και το endpoint επιστρέφει 404.

Για μελλοντική τοπική τεχνική δοκιμή, ο διαχειριστής θα ορίσει EVVARDIA_GUIDANCE_ENABLED=1, EVVARDIA_GUIDANCE_MODEL, OPENAI_API_KEY και EVVARDIA_GUIDANCE_CATALOG (διαδρομή σε κατάλογο JSON). Ο κατάλογος πρέπει να έχει ελεγχθεί από τον υπεύθυνο ειδικό. Περιέχει τα κλειδιά after_shift, before_shift και recurring. Η τιμή κάθε κλειδιού είναι λίστα με 1–12 κάρτες, καθεμία με δύο πεδία κειμένου today και next_days. Η ενεργοποίηση ελέγχεται στον διακομιστή και απαιτεί επανεκκίνηση. Για απενεργοποίηση αφαιρέστε το EVVARDIA_GUIDANCE_ENABLED ή ορίστε το σε 0.

Το μοντέλο λαμβάνει μόνο το κλειδί της θεματικής και τις αντίστοιχες εγκεκριμένες κάρτες. Επιλέγει κάρτα με αριθμητικό ευρετήριο. Τα κείμενα που εμφανίζονται προέρχονται από τον κατάλογο, ακόμη και αν η υπηρεσία επιστρέψει άκυρη απάντηση ή αποτύχει. Σε αυτή την περίπτωση εμφανίζεται η πρώτη κάρτα της θεματικής. Δεν διαβιβάζονται προσωπικές απαντήσεις, κωδικοί συμμετεχόντων ή δεδομένα wearable. Η ανθρώπινη υποστήριξη παραμένει χωριστή. Η προαιρετική καταγραφή χρήσης των κατευθύνσεων δεν περιλαμβάνεται σε αυτή την έκδοση.
